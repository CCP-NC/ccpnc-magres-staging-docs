# CCP-NC Magres Database — Staging

Welcome to the user documentation for the **staging deployment** of the CCP-NC Magres Database, built on the [NOMAD Oasis](https://nomad-lab.eu/) platform.

The Magres Database is a repository of first-principles computational results for solid-state NMR crystallography, stored in the Magres (`.magres`) format. It provides a central platform for researchers to share, explore, and use data associated with calculations of NMR parameters in solid-state structures. The format itself is defined in the [official Magres format specification](https://www.ccpnc.ac.uk/docs/magres/magres-format.pdf).

!!! warning "This is the staging environment"
    You are looking at documentation for the **staging** deployment at
    [magres-staging.psdi.ac.uk](https://magres-staging.psdi.ac.uk/nomad-oasis/gui/about/information). Staging is used to test new features and community workflows before they reach the production site, so some details described here — particularly around login — are specific to staging and will differ once the equivalent production documentation is published.

## What you can do here

- **Search and browse** published NMR crystallography entries without an account.
- **Log in** (by invitation, or via an ORCID sandbox account — see [Logging In](getting-started/authentication.md)) to upload your own calculations.
- **Organize entries into datasets** for sharing and citation.
- **Update metadata** on your own entries, including bulk edits via CSV.
